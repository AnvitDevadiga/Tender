Start a run

Two honest paths: run the pinned fixture locally, or queue a run through the API for a worker to claim. The dashboard only reports what gets recorded.

1 · Run the pinned fixture

python -m tender run-experiment \
  --manifest experiments/retry-ablation-v1.toml \
  --dataset benchmarks/tasks.jsonl \
  --output results/fixture-retry-ablation.json

2 · Or queue through the API + worker

# Terminal 1 — API on loopback
uvicorn tender.api:app --port 8000

# Terminal 2 — worker (needs TENDER_WORKSPACE_ROOT + a Docker sandbox)
python -m tender worker

# Terminal 3 — queue a run
curl -s -X POST http://127.0.0.1:8000/runs \
  -H 'content-type: application/json' \
  -d '{
    "workspace": "your-fixture-name",
    "config": {"sandbox": "docker"},
    "issue": {"repository": "local/fixture", "title": "Fix the percentage bug"}
  }'
Cancelling only works while a run is queued; once a worker claims it, the workflow decides the outcome.
