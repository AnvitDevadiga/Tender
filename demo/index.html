01 / MethodThe system

A result should
come with proof.

An agent’s answer is only the beginning. Tender pins the task to a specific code version, runs the change, and checks the exact patch against independent tests.

Every run leaves a record: what the agent changed, which checks passed, how long it took, and how many tokens it used. When cost is unavailable from the provider, it stays unknown.
